## Hello World Feature

This repository includes a simple Python feature to print "hello world".

### Usage

You can use the feature in three ways:

1. Run the script directly:
   ```
   python hello_world.py
   ```

2. Import and use the function in your code:
   ```python
   from hello_world import print_hello_world
   print_hello_world()
   ```

3. Run the demo script:
   ```
   python demo.py
   ```

### Testing

Run the tests with:
```
python test_hello_world.py
```
