# Vulcan

A Python 3 implementation of the vulcan-old project.

## Overview

Vulcan is a versatile tool designed to help with system operations, data processing, and automation tasks. This implementation is a Python 3 rewrite of the original project.

## Features

- Command-line interface for easy interaction
- Modular architecture for extensibility
- Comprehensive test suite
- Python 3 compatibility

## Installation

```bash
pip install -e .
```

## Usage

```bash
vulcan --help
```

## Development

### Setup Development Environment

```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -e ".[dev]"
```

### Running Tests

```bash
pytest
```
